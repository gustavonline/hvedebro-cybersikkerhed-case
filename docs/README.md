## Struktur
- `01-overblik/` – samlet situationsbillede
- `02-governance/` – politikker (inkl. AI)
- `03-analyse/` – modenhed og risiko
- `04-roadmap/` – prioriterede initiativer og faseplan 1-4
- `05-praesentation/` – slides, noter og eksamensguide

## Kildemateriale i roden af repo
- `Hvedebro Maskinfabrik fuld case beskrivelse.md`
- `hvedebro-cybersikkerhed-caseanalyse.md`

- `undervisning-slides/` (moduler og noter)
