## Struktur
- `docs/` – ny hovedstruktur til eksamensarbejde
  - `01-overblik/`
  - `02-governance/`
  - `03-analyse/`
  - `04-roadmap/`
  - `05-praesentation/`
- `hvedebro-cybersikkerhed-caseanalyse.md` – tidligere kondenseret analyse
- `Hvedebro Maskinfabrik fuld case beskrivelse.md` – fuld casebeskrivelse
- `potentielle intiativer.png` – input til initiativområder
- `undervisning-slides/` – undervisningsmateriale (moduler/noter) brugt som metode-reference
- `Eksamensslides_Hvedebro_10min.md` – oprindeligt slideoplæg (input)

## Fokus i den nye dokumentpakke
- Faseplan **1-4** (ingen fase 0)
- Kvantitativ risikoanalyse (score = sandsynlighed × konsekvens) + 4 behandlingsvalg (Mitigere/Undgå/Overføre/Acceptere)
- Modenhedsanalyse (CSF-inspireret)
- IT-sikkerhedspolitik med NIS2/ISO27001-retning
- Fremtidsperspektiv: digitalisering, hjemmearbejde, awareness, cloud/lokal styring, AI-politik og AI-audit
